### Great Learning Auto-Player & Next

My mama used to tell me I'm smart but lazy. Mama has never been wrong.

Automatically plays Great Learning course videos, prevents pausing when switching tabs, and advances to the next video when finished.

### Features
- **Auto-advance**: Clicks the next video or lesson item automatically upon completion.
- **Background playback**: Bypasses visibility detection so playback does not pause when you switch tabs or minimize the window.
- **Auto-play & Mute**: Starts videos automatically and mutes audio by default.
- **Speed control**: Defaults to 2.0x playback speed.

### Configuration
Edit the constants at the top of the script if needed:
- `PLAYBACK_SPEED`: Set playback speed (default: `2.0`).
- `AUTO_MUTE`: Set to `false` if you want sound enabled (default: `true`).

### Usage
Install with Tampermonkey or Violentmonkey, then open any course video on `olympus.mygreatlearning.com`.
